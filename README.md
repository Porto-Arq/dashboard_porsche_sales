# 🏁 Painel de Vendas Porsche

Dashboard interativo desenvolvido para o desafio de projeto da DIO.

## 🔗 Link do Painel no Ar
👉 [Acessar a Dashboard]([https://github.com/Porto-Arq/dashboard_porsche_sales))

## 📊 Perguntas de Negócio Respondidas
1. Quais os modelos mais vendidos por ano do veículo?
2. Qual o ano de modelo de carro mais vendido (líder de volume)?
3. Qual o modelo mais popular em cada cidade?

## 🧹 Tratamento dos Dados
Os preços e anos foram convertidos em números puros. 
Os campos de data com erro (`INVALID`) foram limpos e definidos como nulos (`null`)
no JavaScript para não quebrar os filtros da tela.
